# F1 차량용 유체 흐름 시뮬레이션 엔진

## 📌 프로젝트 개요

이 프로젝트는 F1 차량의 공기역학적 성능을 분석하기 위한 **유체 흐름 시뮬레이션 물리엔진(CFD 엔진)**입니다.  
나비에-스토크스 방정식을 기반으로 공기 흐름을 정밀하게 계산하며, 차량 형상 주변의 유동, 항력, 다운포스 등을 예측하는 것을 목표로 합니다.

> 초기에는 2D 구조 격자 기반 시뮬레이터로 시작하여, 향후 3D 확장 및 난류 모델 적용까지 발전시킬 계획입니다.

---

## ✅ 기능 요구사항 (Functional Requirements)

| ID  | 항목             | 설명                                              |
| --- | ---------------- | ------------------------------------------------- |
| FR1 | 유체 흐름 계산   | 나비에-스토크스 방정식을 기반으로 속도, 압력 계산 |
| FR2 | 격자 기반 계산   | Structured / Unstructured Mesh 상에서 수치 해석   |
| FR3 | 경계 조건 처리   | 벽, 입출구, 대칭 등 다양한 경계 조건 구현         |
| FR4 | 시간 변화 추적   | 시간 루프 기반의 Transient(비정상상태) 시뮬레이션 |
| FR5 | 차량 외형 모델링 | STL/CAD 형상 입력 및 외부 유동 계산               |
| FR6 | 시각화 기능      | 속도 벡터, 압력 분포, 유선 등 시각적 출력         |
| FR7 | 결과 저장        | 시뮬레이션 데이터를 VTK, CSV 등으로 저장          |
| FR8 | 병렬 처리 지원   | GPU 가속 및 멀티스레딩 등 고속 연산 처리 가능     |

## ✅ 비기능 요구사항 (Non-Functional Requirements)

| ID   | 항목   | 설명                                           |
| ---- | ------ | ---------------------------------------------- |
| NFR1 | 정확도 | 박리, 와류, 재부착 등 정밀한 유동 현상 반영    |
| NFR2 | 성능   | 실용적 시뮬레이션 속도를 위한 최적화           |

| NFR4 | 유연성 | 다양한 차량 형상 및 조건에 적용 가능           |
| NFR5 | 사용성 | 시각화 및 데이터 분석이 용이한 인터페이스 제공 |
| NFR6 | 이식성 | 다양한 OS 및 플랫폼에서 실행 가능 (CLI/GUI 등) |

---

## ✅ 기술적 요구사항 (Technical Requirements)

| 항목      | 세부사항                                          |
| --------- | ------------------------------------------------- |
| 수치 해석 | 나비에-스토크스 방정식, 연속 방정식, FVM 기반     |
| 압력 계산 | Poisson 방정식, Conjugate Gradient / Multigrid    |
| 난류 모델 | 초기: Laminar → 향후: k-ε, k-ω (RANS)             |
| CAD/격자  | STL 불러오기, Gmsh/snappyHexMesh 연동             |
| 구현 언어 | Python(프로토타입), C++/CUDA 또는 OpenFOAM 기반   |
| 시각화    | ParaView, Matplotlib, 또는 WebGL 기반 시각화 도구 |

## 🛠 개발 로드맵

| 단계  | 목표                      | 주요 기능                             |
| ----- | ------------------------- | ------------------------------------- |
| 1단계 | 2D 유체 시뮬레이터 구현   | 속도/압력 계산, 시각화, 경계조건 처리 |
| 2단계 | 압력 보정 알고리즘 정교화 | Poisson solver 도입                   |
| 3단계 | 차량 외형 모델링 연동     | STL 파일 기반 형상 적용               |
| 4단계 | 3D 유동 확장 및 병렬 처리 | CUDA/멀티스레드 기반 고속 계산        |
| 5단계 | 난류 모델 및 최적화 적용  | k-ε, k-ω 모델 + 설계 최적화 모듈      |
